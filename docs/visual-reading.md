# 阅读层（VN 引擎）规格（v1.0，步骤三）

> 本文件是步骤三的可读性口径：打字机怎么走、选项怎么计时、标题卡与史实注怎么停、自动/跳过到什么程度。
> 节点数据契约见 `docs/script/README.md` §6；存档字段见 `docs/state-schema.md`；坐标见 `docs/ui-layout.md` §7。
> 一句话原则：**节奏服务于文字**——宁可慢一拍，也不要让玩家在字还没说完时就替角色做决定。

## 1. 目标与非目标

- 目标：完整播放序章（p001–p044，48 个节点，其中 41 句正文），做到旗标生效、存档/读档、超时选项有代价。
- 非目标（留给后续步骤）：门板小游戏（步骤四）、第一章及以后（步骤五）、音效与转场（步骤六）、完整七张图鉴浏览页（步骤五）。
- 不使用计时器驱动的逐字动画之外的动效；不做逐字回退、不做字幕高亮、不做配音。

## 2. 打字机与分页

- 速度：`settings.textSpeed` 字/秒（10–60，默认 30）；每字毫秒 `charMs = clamp(1000 / textSpeed, 12, 100)`，用 `requestAnimationFrame` 累计时间推进，不用 `setInterval`。
- 一屏 = 一页：正文框 1108×66、26px/1.8，只放得下约 3 行。超出的句子按**字符二分**分页（测量屏外 `#vn-measure` 的 `scrollHeight ≤ 66`），不截断、不省略。
- 三次点击的语义固定：**第一次补全本页 → 第二次翻到下一页 → 第三次推进下一句**。键盘空格/回车等价。
- 推进后 100ms 内忽略输入，避免 pointerdown 与 click 双触发跳句。
- `prefers-reduced-motion` 或设置里「减少动效」：直接整页显示，不逐字。
- 字号档位 100% / 115% / 130%，作用在 `--text-scale`；换档只影响之后的节点，不重排当前已显示页。

## 3. 选项与限时

- 选项面板：提示句在 360,262；选项组 360,300，每张 560×64、间距 16。
- 选项卡三行：序号 A/B、文案（≤14 字）、代价（≤22 字，14px 墨黑 70%）。**代价必须可见**——它是道德取舍的全部信息，不许藏进 tooltip。
- 限时：`node.timeout` 秒，底部 4px 进度条从满到空（CSS 变量 `--choice-progress`，0–1）。
- 超时：立即按 `defaultOption` 结算，`timedOut: true` 写进 `choices` 日志；提示「超时：已按默认选项结算」，300ms 后进入下一节点。**超时不免费**：默认项自带的代价照常写入。
- 点选后 240ms 进入下一节点，期间选项禁用，避免连点。
- 计时在暂停、设置、页面不可见（`visibilitychange`）时冻结；恢复后从剩余时间继续，不重头计。

## 4. 标题卡与史实注

- 标题卡全屏（0,0,1280,720）：章名 44px、朱砂细线、副题 18px；1200ms 自动关，点击/空格立即关。
- 两处使用：新游戏入口「序章 · 于都」；`p043` 的「第一章 · 湘江」。
- 读档继续时不重放入口卡（卡是“开新局”的仪式，不是章节数据）。
- 史实注：单张弹窗 190,80,900×560，四块固定顺序——标题 / 类型徽章 / 正文 / 出处；“有不同说法”单独一行，写在正文与出处之间。
- 关闭史实注 = 记进 `state.codex`（去重）+ 立即存档；同一张不重复弹。
- 图鉴的人物一律带「虚构人物，非史料人物」落款。
- 标题菜单的「史实图鉴」在步骤三仍是提示「步骤五接入」，不做半成品列表页。

## 5. 自动与跳过

- 自动：每页显示完成后停留 1200ms 再推进；遇到选项、小游戏入口、结算、标题卡、史实注**自动停**，不替玩家做选择。
- 跳过：只对**本次会话已读**的节点开放（`seenNodes` 只存内存，不写存档）；设置里关掉「跳读已读」时按钮置灰并提示原因。
- 两个按钮都是 `aria-pressed` 开关；状态不持久化——刷新后回到手动。

## 6. 暂停与设置

- 暂停遮罩四行：继续 / 设置 / 返回地图 / 回到标题。Escape 开关暂停；关闭后焦点回到原元素。
- 暂停冻结打字机与选项计时；`paused` 不进存档。
- 设置六项：文字速度（10–60，步长 5，显示“30 字/秒”）、字号（100/115/130%）、音量（0–100，步骤六才发声，先存值）、静音、减少动效、跳读已读。
- 改完立即生效并 `saveNow()`；不做「恢复默认」按钮（默认值写死在 `docs/state-schema.md` §2，重置=重开）。

## 7. 存档与恢复

- 仍是 `xiangbei.save.v1`，11 个持久键不变；节点图是扁平数组 + `when` 条件，存档只存 `chapterId` + `nodeId`。
- 保存点：进入节点、选项结算、标题卡关闭、史实注关闭、设置变更、章末解锁、小游戏/结算面板继续。
- 刷新恢复到 `nodeId`；若该节点在当前旗标下不可见（例如读档后旗标被改），按坏档处理：备份 `.bad`、重置、提示，不白屏。
- 单次序列化上限 4096 字节；超限不写、控制台报错、提示“存档异常”。
