# 《向北》故事圣经（v0.1）

> 用途：剧本、分镜、UI 文案的唯一人物/道具/旗标口径。与代码冲突时，以本文件 + 计划书为准；史实见 docs/sources.md。
> 原则：人少而准；每人只承担一个记忆点；不喊口号；真实人物只进史实注。

## 1. 一句话与主角

**一句话**：一个于都少年背着一块门板走完长征——正面记名字，背面画路线。

| 项 | 内容 |
|---|---|
| 姓名 | 满崽（大名刘满仓） |
| 年龄 | 16 |
| 籍贯 | 江西于都 |
| 身份 | 红一方面军某连文书 |
| 特长 | 识字、写标语、记名字 |
| 口头禅 | “我记一下。” |
| 弱点 | 怕黑、怕枪声；起初把“记住”当成写字 |
| 弧光 | 从“记在本子上”到“记在心里”；从“跟着走”到“替倒下的人走” |

**虚构声明**：满崽与名册人物均为虚构，非史料人物；不借用真实烈士姓名。

## 6. 写作口径

- 第一人称“我”；短句；每段不超过 3 行；能演出来的，不靠旁白解释。
- 不喊口号；精神落在动作和代价上，结尾不总结“长征精神是什么”。
- 不写领导人台词；真实人物只进“史实注”，不进剧情。
- 死亡用“名字被划掉”和留白；不写血腥，不消费苦难。
- 每章至少一个“名字”记忆点；终章点名回收；不要让所有死者都叫“战士”。
- 数字前后一致：8.6 万、3 万、3.7 万、6 条船、37 名船工、22 勇士、7000 人。
- 方言只做点缀，1–2 句即可，附一句普通话解释；不写整段土话。
- 敌人不脸谱化；只作为时间压力和追兵存在，不写“打鬼子”关卡。
