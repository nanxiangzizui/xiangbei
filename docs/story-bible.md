# 《向北》故事圣经（v1.0）

> 用途：剧本、分镜、UI 文案的唯一人物/道具/旗标口径。与代码冲突时，以本文件 + 计划书为准；史实见 docs/sources.md，图鉴文案见 docs/codex.md。
> 原则：人少而准；每人只承担一个记忆点；不喊口号；真实人物只进史实注。
> 版本：v1.3.0-dev（2026-11-06，人物命运四路线已实现）。v1.2 删除四关小游戏；v1.3 加三次救人危机、四路线、名册回廊。v0.1 的“细妹草地病倒 / 灶王归队 / 林先生掉队”已按剧本改写，见 §4.3。

## 1. 一句话与主角

一句话：一个于都少年，背着一块从家门上锯下来的木板走完长征——正面写字，背面刻一个“北”。

| 项 | 内容 |
|---|---|
| 姓名 | 满崽（大名刘满仓） |
| 年龄 | 16 |
| 籍贯 | 江西于都 |
| 身份 | 红一方面军某连文书（连队番号虚构） |
| 特长 | 识字、写标语、记名字 |
| 口头禅 | “我记一下。” |
| 弱点 | 怕黑、怕枪声；起初把“记住”当成写字 |
| 弧光 | 从“记在本子上”到“记在心里”；从“跟着走”到“替倒下的人答到” |

**虚构声明**：满崽与名册人物均为虚构，非史料人物；不借用真实烈士姓名。片头出现一次，图鉴落款再出现一次。

## 6. 写作口径

- 第一人称“我”；短句；单条台词不超过 40 字；能演出来的，不靠旁白解释。
- 不喊口号；精神落在动作和代价上；结尾不总结“长征精神是什么”。
- 不写领导人台词；真实人物只进“史实注”，不进剧情。
- 死亡用“名字被划掉”“蹲下没再站起来”和留白；不写血腥，不消费苦难。
- 每章至少一个“名字”记忆点；终章点名回收；不让所有死者都叫“战士”。
- 数字前后一致（见 §4.2 台账）：8.6 万、3 万、3.7 万、6 条船、37 名船工、22 人、7000 余人。
- 方言只做点缀，1–2 句即可；不写整段土话。
- 敌人不脸谱化；只作为时间压力和追兵存在，不写“打鬼子”关卡。
- 不用现代网络梗、穿越梗、轻佻吐槽；不用“同志们，冲啊”式口号台词。
