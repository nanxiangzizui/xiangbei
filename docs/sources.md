## 4. 文学与史实

- 《七根火柴》《金色的鱼钩》是小说，不是史料；可用于氛围，**不可**进“史实注”，不可当史实引用。
- 回忆录（如王平回忆录、杨成武回忆录）：可作为细节来源，但标注“回忆录”，对话不复述成史实台词。
- 真实人物（毛泽东、周恩来、朱德、刘伯承、陈树湘、杨成武等）只进史实注，不进游戏剧情；不虚构他们的对话，不替他们做决定。
