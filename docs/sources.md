## 3. 文学与史实

- 《七根火柴》《金色的鱼钩》是小说，不是史料；可用于氛围，不可进“史实注”，不可当史实引用。
- 纪实文学、回忆录与史实分开标注；回忆录里的对话不直接当史实台词。
- 真实人物（毛泽东、周恩来、刘伯承、陈树湘、黄开湘、杨成武等）只进史实注，不进游戏剧情；不虚构他们的对话。
