## 2. 文风

- 第一人称“我”；短句；每段不超过 3 行；一段只做一件事。
- 不喊口号；不写“这就是长征精神”；让动作和代价说话。
- 不写领导人台词；不虚构真实人物的对话；需要交代背景时用旁白/文件/史实注。
- 死亡用“名字被划掉”和留白；不写血腥特写；不把牺牲做成分数。
- 敌人不脸谱化；不写“打鬼子”关卡；敌人只作为追兵/时间压力。
- 数字写法统一：8.6 万、3 万、3.7 万、7000；日期在正文用“1934 年 10 月 17 日”，表格用“1934-10-17”。
- 方言只做点缀：于都客家话 1–2 句，后接普通话解释；不写整段土话。
- 每章至少一个“名字”记忆点；终章点名回收；死者有名有姓，不叫“一个战士”。

## 3. 禁用 / 慎用

- 禁用：打鬼子、共匪、长征大捷、完胜、全歼、血流成河、逆袭、开挂、爽文、燃爆。
- 慎用：牺牲（不滥用）、敌人（尽量写“追兵/敌军”）、兄弟（现代感强，少用）。
- 不把“吃苦”写成奇观；不把“牺牲”写成游戏分数；不做“完美通关”评价。

## 4. 史实审校清单

- [ ] 7 条锚点每条至少 2 个出处；链接交差前补齐。
- [ ] 大事件结局未改：湘江必败、遵义必开、泸定必夺。
- [ ] 无领导人台词；真实人物只出现在史实注。
- [ ] 争议细节标注“有不同说法”（X 光机、22 人牺牲数、金沙江船数、夹金山高度）。
- [ ] 文学与史实分开；《七根火柴》《金色的鱼钩》未当史料。
- [ ] 片头/图鉴有“人物虚构”声明。
- [ ] 无血腥特写；死亡用划名/留白。
- [ ] 敌人未脸谱化；无“打鬼子”关卡。
- [ ] 数字前后一致；未把约数写成精确数。
- [ ] 每条史实注有出处编号（S1–S7）。

## 5. 命名

- 人物名用 20 世纪 30 年代江西/湖南/四川常见名：满崽、细妹、冬生、灶王、飞毛腿、林先生、张老幺。
- 不用现代梗、网名、英文名；不撞真实烈士姓名。
- 船工用“张老幺”这类虚构名；不把真实船工的名字安在虚构角色身上。
- 同一个人的称呼前后统一：老周、何指导员、细妹、冬生、灶王、飞毛腿、林先生、张老幺。
