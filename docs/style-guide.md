> 写剧本、UI 文案、史实注时先扫一遍。原则：短、准、不喊口号；真实人物只进史实注。
> 配套：剧本格式见 `docs/script/README.md`；数字见 `docs/story-bible.md` §8；图鉴见 `docs/codex.md`。

## 2. 文风

- 第一人称“我”；短句；一段不超过 3 行；一段只做一件事。
- 单条台词 ≤ 40 字；选项 ≤ 14 字；选项代价 ≤ 22 字（手机上两行放得下）。
- 不喊口号；不写“这就是长征精神”；让动作和代价说话。
- 不写领导人台词；不虚构真实人物的对话；交代背景用旁白/文件/史实注。
- 死亡用“名字被划掉”“蹲下没再站起来”“没人应”三种写法；不写伤口与遗体。
- 敌人不脸谱化；不写“打鬼子”关卡；敌人只作为追兵与时间压力。
- 数字写法：正文用“八万六千人”“三万七千人”式汉字（万位以上），表格用 8.6 万；日期正文写“1934年10月17日”，表格写 1934-10-17。
- 正文里的每个数字必须能在 `story-bible.md` §8 台账查到编号；查不到就删。
- 方言只做点缀：1–2 句，不附翻译也能懂；不写整段土话。
- 每章至少一个“名字”记忆点；终章点名回收；死者有名有姓，不叫“一个战士”。

## 3. 禁用 / 慎用

- 禁用：打鬼子、共匪、长征大捷、完胜、全歼、血流成河、逆袭、开挂、爽文、燃爆。
- 慎用：牺牲（不滥用）、敌人（改“追兵/敌军”）、兄弟（现代感强，少用）。
- 不把“吃苦”写成奇观；不把“牺牲”写成游戏分数；不做“完美通关”评价。
- 不用现代网络梗、穿越梗、轻佻吐槽；不写“同志们，冲啊”。

## 4. 史实审校清单（交差前逐条打勾）

- [ ] 7 条锚点每条至少 2 个出处；链接已点开确认（S1–S15）。
- [ ] 大事件结局未改：湘江必败、遵义必开、泸定必夺。
- [ ] 无领导人台词；真实人物只出现在史实注。
- [ ] 争议细节标注“有不同说法”：渡口数、X 光机、22 人姓名、金沙江船数、草地减员。
- [ ] 文学与史实分开；《七根火柴》《金色的鱼钩》未当史料。
- [ ] 片头/图鉴有“人物虚构”声明。
- [ ] 无血腥特写；死亡用划名/留白。
- [ ] 敌人未脸谱化；无“打鬼子”关卡。

- [ ] 每张史实注有类型（史实/回忆录/有不同说法）与出处编号。

## 5. 命名

- 人物名用 20 世纪 30 年代江西/湖南/四川常见名：满崽、细妹、冬生、灶王、飞毛腿、林先生、张老幺。
- 不用现代梗、网名、英文名；不撞真实烈士姓名。
- 船工用“张老幺”“老鸦”这类虚构名；不把真实船工的名字安在虚构角色身上。
- 同一个人的称呼前后统一：老周、何指导员、细妹、冬生、灶王、飞毛腿、林先生、张老幺。
- 称呼随关系变化要写进圣经：目前满崽对老周称“老周”（不称“连长”），对何指导员称“何指导员”。

## 6. 图鉴（史实注）写法

- 结构固定四行：标题 / 类型 / 正文（120–220 字）/ 出处编号。
- 类型只有三种：史实、回忆录、有不同说法（可组合，如“史实 ＋ 有不同说法”）。
- 只写可核实的事；不确定的进 `sources.md` §5“停用与待核”，不进图鉴。
- 图鉴不出现虚构人物。
