>
> 舞台内禁用文本选中（`#stage, #stage * { user-select: none }`）：双击/三击只推进剧情，不出现蓝色选区；游戏内只有滑杆，没有需要复制的文本。

## 4. 字号与层级

| 用途 | 字号 | 行高 | 备注 |
|---|---|---|---|
| 游戏标题 | 96 | 1.0 | 得意黑；字距 12px |
| 章节标题 | 44 | 1.2 | 字距 8px |
| 正文 | 26 | 1.8 | 手机缩放后约 14px；可调 textScale |
| 姓名 | 18 | 1.2 | 粗体 |
| 选项 | 22 | 1.4 | 最多 3 行 |

| 最小字号 | 14 | — | 任何可见文字不小于 14px（舞台坐标） |

**层级**（括号内是 `style.css` 令牌）：画布 `--z-art` 0 → 场景 `--z-scene` 1 → 人物 `--z-figure` 10 → HUD `--z-hud` 20 → 对话框 `--z-dialogue` 30 → 状态提示 `z=35` → 选项/多选 `--z-choice` 40（二者互斥，同一层）→ 弹窗 `--z-modal` 50 → 转场 `--z-transition` 60 → 暂停 `--z-pause` 80 → 图鉴 `--z-gallery` 82 → 单张史实注 `--z-codex` 84 → 剧情分支 `--z-branch` 86 → 分支详情 `--z-branch-detail` 88 → 提示 `--z-toast` 90 → 调试 `--z-debug` 95 → 横屏提示 `--z-orientation` 100。
**焦点**：键盘焦点环 = 2px 朱砂外环 + 2px 纸白内衬（`box-shadow`）；不要只靠颜色表达选中。
**热区**：所有可点元素 ≥44×44；单选/多选整卡可点；844×390 下多选确认按钮 96 逻辑≈52 CSS px、选项 82 逻辑≈44.4 CSS px；暂停按钮 96×96。

## 5. 适配

| 屏幕 | 缩放 | 处理 |
|---|---|---|
| 1920×1080 | 1.5 | 居中，留边 |
| 1366×768 | 1.067 | 居中，留边 |
| 1280×720 | 1.0 | 基准 |
| 844×390 手机横屏 | 0.542 | 按高度缩放；正文 26→14px；提供 textScale 1.15/1.3；96 逻辑≈52 物理（多选确认热区下限） |
| 390×844 竖屏 | — | 显示“请横屏”；浏览器不跟随转屏时提示用系统浏览器打开 |
| 超宽屏 | 按高 | 左右留纸白；不拉伸 UI |

- 使用 transform: scale() 缩放整个舞台；不要逐元素改 px。
- 触摸坐标用 getBoundingClientRect() 换算；不要用 offsetX/offsetY。
- 手机横屏底部安全区 ≥16px；避免刘海遮挡。
- 减少动效：prefers-reduced-motion 时关闭闪白/震动，只保留淡入淡出。
