【旁白】1934年10月17日，于都河上起雾。
【旁白】雾里看不见对岸，只看得见火把。火把从村口一直排到水边。
【旁白】河上有一座浮桥。桥面是门板，一块压着一块，压得很紧。
【旁白】桥板是各家送来的：门板、床板，还有一副寿材，黑漆没干透。
【旁白】有人问，寿材也拿去搭桥？老人说，人都要走了，留着装谁。

[[bg:yudu_night]]
【旁白】我家的门，是村里最后一扇整门。
【旁白】门上有我刻的身高线，一道一道。最高的那道，到娘的肩膀。
【旁白】娘把锯子架上门轴。锯末落在我脚背上，还是热的。
【满崽】娘，门没了，还像个家吗？
【娘】家在人身上。
【娘】你要走远路。这块板子带上，写字垫着，下雨顶着。
【娘】路上要是想家，就把板子立起来，看看它从哪儿来。
【娘】路要从家门口开始。

【旁白】老周在祠堂门口点人。我蹲在门槛上，拿铅笔一个一个记。
【老周】满崽，名字比枪重。记清楚。
【旁白】他念一个名字，队伍里有人应。念到没人应的，他自己低低应一声。
【旁白】我抬头看他。他没看我，只把名单往下压了压。
【满崽】我记一下。
【旁白】那一夜，我把全连的名字抄了一遍。抄到最后一个，手是抖的。
【旁白】名字写歪了，我用指甲刮掉重写。刮破了两处纸。

【旁白】天快亮时，行囊定了。带走的摊在地上，只有一小堆。
【旁白】灶王把锅擦了一遍，又擦一遍，像要把它擦亮。
【灶王】大锅留下，小锅我背。人先走。
[[if:item.door]]
【旁白】我在纸上写：水缸、柴、一口大锅。门板那一行，空着。
[[else]]
【旁白】我在纸上写：水缸、柴、一口大锅、一扇门。
[[end]]
【旁白】写完，我把纸压在灶台边。压得很平。

[[bg:yudu_river]]
【旁白】出发时，火把连成另一条河。我们从那一条河上走过去。
【旁白】浮桥在脚下晃。我不敢低头，只看前面人的后脑勺。
【旁白】前面的人踩空，半条腿陷进水里，后面的人一把拽住他的背包带。
【冬生】号一响就走，别回头。
【旁白】娘挤到桥头，把一根缝衣针别在我衣襟上。针尖朝里。
【娘】衣裳破了，自己缝。

[[bg:yudu_night]]
【旁白】上了南岸，我把门板翻过来，用铅笔画了一个字。画得很大，占了半块板。
【旁白】北。
【旁白】画完，我用手掌按了按，怕雨水泡开。
【旁白】按完才想起，铅笔会写秃。路还长。
