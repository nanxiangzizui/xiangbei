【旁白】1935年10月19日，吴起镇。土是黄的，天很高。
【旁白】镇口的窑洞墙上刷着标语：北上抗日。
【旁白】老乡站在门边看我们，不说话。有人把一筐土豆放在路口，转身就进屋。
【旁白】有人在井边打水，先给伤员。轮到我，只剩半瓢，底的泥一晃一晃。
【旁白】队伍停下来。第一次没有人喊“快”。

【林先生】满崽，借你的门板用一下。标语写不下，得找块平的。
【满崽】……
【旁白】我把门板解下来，靠在墙上。背面那个“北”字，被雨泡得发白。
【林先生】这字谁写的？
【满崽】我。
【林先生】留着。标语写在正面，字写在背面，正好。
【旁白】她先用粉笔打格子。一个字一格，写一个，退后两步看看，再写下一个。

【旁白】点名的时候，天刚亮。
【旁白】念到的人答“到”。队伍站成三排，前一排能看见后一排的鞋。
【旁白】名册翻到第三页。纸已经软了，像一块布。

【旁白】念到何指导员。他在别的连，那边有人应了一声。
【旁白】念到细妹。她答“到”，声音比平时高。
【旁白】念到林先生。她正在收粉笔，回头应了一声。

【旁白】念到老周。队伍里没有人应。
【满崽】到。
【旁白】我替他答了一声。声音不大，队伍里没人看我。
【旁白】念到灶王。我又答了一声。
【旁白】念到飞毛腿。我答到一半，答不下去。
【旁白】后面的名字，是冬生替我答完的。
【旁白】他念得比我快，比我稳。念完最后一个，他把名册合上，递还给我。
【旁白】名册上有一行墨，被他的手汗洇开了。

【交互】点名｜45s｜按名册顺序念名；活着的人自己答，没人应的由玩家替他答
【结算】点名｜全连出发 104 人，到吴起 19 人（虚构）；中央红军出发 8.6 万余人，到陕甘 7000 余人（史实）

【旁白】后来有人告诉我，出发的时候，中央红军八万六千人。
【旁白】到陕北，七千余人。
【旁白】全连出发一百零四，到吴起十九。
【旁白】十九个人，站成三排。前排空着的位置，风从那儿过。

【结算】五卡｜理想信念 / 不怕牺牲 / 独立自主 / 顾全大局 / 依靠人民（亮或暗，附一句你的记录）
【旁白】会后，指导员让我把五句话抄在纸上，贴在连部门口。
【旁白】我抄了五句。抄完，在最后添了一行小字：以上，都是别人教我的。

【旁白】散了会，我一个人走到镇口。风很大，吹得标语哗哗响。
【旁白】娘说过，家在人身上。
【旁白】我把名册翻开。名字有的还在，有的被我划掉了。
【旁白】划掉的那些，我没有划第二遍。
【旁白】最后一页是空的。我本来想写点什么。
【旁白】想了很久，只写了一个字。
【旁白】北。
