# 向北 —— 一块门板，两万五千里

**一页设计说明 · v1.9.1-dev · 2026-11-15**

> 本稿按 v1.9.1-dev 现行玩法重写：四段选择 + 三次救人危机 + 行囊 4 格/状态 0–4/门板去向 + 11 条人物结局。v1.2.0 起已删除四关小游戏。PDF 由 `project/tools/design-note.html` 经 Edge 打印生成，随 `dist/` 交付。

16 岁红军文书 · 七段 · 四段选择 + 三次危机 · 11 条人物结局 · 20 分钟设计上限
**虚构人物，非史料人物；历史结局不可改：湘江必败、遵义必开、泸定必夺。**

## 1. 一句话

玩家是 1934 年于都的 16 岁文书“满崽”，背着一块从自家门上锯下的木板，从于都走到吴起；通过对话、行囊取舍、限时选择与三次救人危机，决定带什么、救谁、记住谁、门板到哪里。没有全活，也没有 Game Over；失败只改变代价。

## 2. 怎么玩

- 点击 / 空格 / Enter 推进；单选按 1–4，多选按 1–9 后 Enter 确认；Esc 暂停。设置可调文字速度、字号、总音量/配乐/环境音三个滑块、静音、减少动效、跳读已读。
- 四段选择：序章行囊（8 个半格 = 4 格，门板占 2 格；未满会二次确认）、湘江弃物（6 件带 3 件）、金沙江先渡谁、泸定门板/记名。
- 三次救人危机：泸定飞毛腿（12s）、草地灶王（16s）、草地尽头冬生（12s）；超时按默认项“不救”结算，犹豫也是代价。救人数 + 门板去向 + 你是否倒下，收束为 11 条人物结局；点名 0/7/8 人，连队 18/19 人，没有全活。
- 7 张史实图鉴、48 条成就、分支图、40 档存档、剧情回顾、一周目后章节重玩、结局分享卡/本周目统计；手机请横屏。
