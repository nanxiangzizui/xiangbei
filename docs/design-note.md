**虚构人物，非史料人物；历史结局不可改：湘江必败、遵义必开、泸定必夺。**

## 1. 一句话

玩家是 1934 年于都的 16 岁文书“满崽”，背着一块从自家门上锯下的木板，从于都走到吴起；通过对话、限时取舍和四个小游戏，决定带什么、救谁、记住谁。

## 2. 怎么玩

- 点击 / 空格 / Enter 推进对话；选项按 1–3；Esc 暂停；设置里可调文字速度、字号、总音量/配乐/环境音三个滑块、静音、减少动效、跳读已读。
- 四个小游戏都支持鼠标/触摸，单手可完成：门板拖拽摆放；湘江拖拽弃物；金沙江用数字键调度船次、Shift+数字让船工休息、Enter 确认；泸定在 0.35 秒命中窗口里点亮 22 个光点。
- 没有 Game Over；失败不重开，只改变代价与结算里的一句话。手机请横屏。
- 7 张史实图鉴可从标题、暂停、结局三个入口查看，卡面带缩略图和照片年代说明；结局是“到吴起、点名、放门板”一种，五张精神卡只改变亮度与文案。
- 每章章首卡使用对应场景图、日期与地点；暂停菜单可翻“花名册”，点名前显示“在册”，点名后显示谁应了、谁没应。
