《向北》v1.4 状态、物资与门板系统（设计稿）
2026-11-07
说明：本文件是设计稿，代码尚未按此修改。与旧版冲突时，以本文件为准。

本次已按你的五条决定改：
1. 7(3) 用“冬生赠青稞”解决；
2. 状态 0 = 立即坏结局；
3. 7(5) 优先于坏结局；
4. 门板三个条件并列；
5. 行囊 4 格，物品种类不限，总占格不超过 4 格。

为了让 7(3) 真的可达，“青稞 + 青稞”按 +2 处理（两份青稞煮成一顿）；  
“冬生的青稞 + 我的药”仍按 +1。若你坚持青稞 + 青稞只 +1，7(3) 仍会被坏结局截胡。

一、救人信息
飞毛腿：门板 / 药
灶王：青稞 / 铁锅
冬生：布鞋 / 雨布（无门板）

新增：冬生身上自带一份青稞（0.5 格，初始不计入“我”的行囊）。
“我”救下冬生后，他把这份青稞塞给“我”；剧情文本要写出来。
这份青稞不占行囊，只能当场使用，或与“我”自带的青稞合并使用。

二、行囊与物资
1. 行囊 4 格；物品种类不限，总占格不能超过 4 格。
2. 占格：青稞 0.5、药 0.5、布鞋 1、铁锅 2、门板 2、雨布 2。
3. 物资栏整合所有物资，每件物资有一句描述和一个“使用”框。
4. 门板在物资栏里始终“不可使用”；剧情里仍可铺桥、挡桥、当床板、写字。
5. 雨布在物资栏里只在草地章节可用；剧情里的遮雨、护名册不算“使用物资”。
6. 其他物资在“我”的状态为良好及以下时可以使用。
7. 使用效果：
   - 药 + 青稞：+1 级。
   - 青稞 + 青稞（“我”的青稞 + 冬生赠的青稞）：+2 级。
   - 冬生赠的青稞 + 我的药：+1 级。
   - 布鞋：+1 级。
   - 雨布：+1 级。
   - 铁锅：+2 级。
   - 门板：不能为自己使用。
8. 物资栏随时可打开；限时选项进行期间禁止打开，选项结算后再弹。

三、状态值
1. 状态从高到低：优秀、良好、勉强、差、0。
2. 所有人初始状态：良好。
3. “我”的状态显示在屏幕左上角。
4. “我”的状态在草地结束时下降一级。
5. 状态为“差”时，弹出物资栏警告：立刻使用物资补充；拒绝或没有可用物资，直接触发坏结局。
6. 状态到 0：立即触发坏结局，不再开物资栏；唯一例外是 7(5)。
7. “一直保持优秀”指：每次救人降级、草地结束降级、用完物资之后，最终结算时仍是优秀。不是每一秒都必须优秀。
8. 每当“我”的状态发生变化，都弹出物资栏，告诉玩家是否使用物资提升状态；状态到 0 时不弹，直接结算。

四、“我”的状态变化
1. 无门板：
   - 救 1 人：状态不变。
   - 救第 2 人：救完立刻降 1 级。
   - 救第 3 人：状态不变。
2. 有门板：
   - 救 1 人：状态不变。
   - 救第 2 人：救完立刻降 1 级。
   - 救第 3 人：救完再降 1 级。
3. 草地结束时，再降 1 级。
4. 判定顺序固定为：
   初始 → 每次救人降级 → 草地结束降级 → 三人帮助（只一次）→ 差警告 / 物资 → 0 / 坏结局 → 门板与结局结算。
5. 救满 3 人后，三人帮助只触发一次，第一次强制触发，不给玩家选择：
   - 当“我”的状态因惩罚降到“差”时，自动 +1 级，回到“勉强”。
   - 若降到 0，帮助无效，仍按 0 处理。
   - 帮助触发后，本局不再触发。
6. 如果“差”警告时三人帮助尚未触发，先触发帮助；帮助后不再是“差”，就不弹警告。
7. 如果帮助已经用过，草地结束又降到“差”，才弹物资栏；没有物资恢复则坏结局。

五、“我”的存活
1. 状态保持在“勉强”及以上，活。
2. 救满 3 人，三人帮助只一次，只能把“差”拉回“勉强”；0 不能救。
3. 状态到 0：坏结局；若同时满足 7(5)，走 7(5)。
4. 状态到“差”且无物资恢复：坏结局；若同时满足 7(5)，走 7(5)。

六、被救者的状态
1. 用药、青稞救人：对方从“差”变为“勉强”。
2. 用布鞋、铁锅、门板、雨布救人：对方从“差”变为“良好”。
3. 冬生被救后额外赠“我”一份青稞，见第一节。
4. 其他人（老周、何指导员、细妹、林先生）不进入这套状态表；林先生只按第九节处理。

七、带出门板的条件
满足以下任意一条即可：
A. “我”的状态一直保持优秀（按第三节第 7 条的口径）。
B. 算上“我”共有 4 人存活，且至少 1 人状态良好。
C. 算上“我”共有 3 人存活，且 2 人状态良好。

说明：
- “4 人”指“我” + 3 名被救者；“3 人”指“我” + 2 名被救者。
- 死亡的人不计入存活人数。
- 草地结束时，如果 A/B/C 一条都不满足，弹出窗口：
  “由于你体力透支，或帮手不足，无法将门板带到终点，你必须舍弃。”
  玩家点击“舍弃门板”后继续。
- 7(5) 是例外：救 3 人、出发时带门板、我死在草地时，门板由其他人带到吴起，不走“舍弃门板”弹窗。

八、结局
出发时带上门板：
(1) 0 人获救，状态一直优秀：自己把门板带到吴起。
(2) 救 1 人，状态没有保持优秀：门板留在草地，没能带出。
(3) 救 2 人，算上“我”共 3 人存活、其中 2 人良好：自己把门板带到吴起。
(4) 救 2 人或 3 人，但未满足带出条件：门板留在草地。
(5) 救 3 人，我最终死在草地：门板由其他人带到吴起；优先于坏结局。

出发时不带门板：
(1) 0 人获救，自己存活。
(2) 救 1 人。
(3) 救 2 人。
(4) 救 3 人。
(5) 救 3 人，且结算时“我”的状态为优秀。

坏结局：
- 状态到 0；或
- 状态到“差”且没有物资恢复；或
- 草地结束仍为“差”且无物资恢复。
- 例外：满足 7(5) 时走 7(5)，不走坏结局。

九、林先生
1. 林先生死亡的直接原因是“我”的死亡：她为了等“我”、找“我”，没等到收容队。
2. 林先生只在两种结局死亡：
   - 7(5)：我死在草地，门板由其他人带出；
   - 坏结局：我在到吴起前死亡。
3. 其他路线林先生存活；不再按“救 2 人必死”处理。
4. 结局结算界面和剧情文本都要写出这层因果，不能只在名单上写“未应”。

十、7(3) 的可达性示例
配置：门板 2 + 药 0.5 + 布鞋 1 + 青稞 0.5 = 4 格。
流程：
1. 用门板外的物资救人：飞毛腿用药，冬生用布鞋；门板保留。
2. 冬生获救后赠“我”一份青稞。
3. 救 2 人：良好 → 勉强。
4. 草地结束：勉强 → 差。
5. 差警告时，用“我的青稞 + 冬生的青稞” +2：差 → 良好。
6. 此时算上“我”共 3 人存活：我良好、冬生良好、飞毛腿勉强；满足条件 C。
7. 7(3) 成立，自己把门板带到吴起。

没有冬生赠青稞，7(3) 会在草地结束时卡在“差”，被坏结局截胡；
若“青稞 + 青稞”只 +1，也会卡在“勉强”，不满足“两人良好”。

十一、其他说明
1. 长征开始时（选完行囊后）弹窗：
   “你当前的状态为良好，是否使用物资将状态提升至优秀？”
   使用物资只是“有机会”触发 0 人获救、自己带门板的结局，不是保证。
2. 7(2) 的“门板留在草地”和 7(4) 的“无法带出”是同一类结果，按救人数分：
   - 7(2)：救 1 人，门板留草地；
   - 7(4)：救 2/3 人，门板留草地。
   不另设“门板留草地”的独立结局标题。
3. 所有结局都不做“最优/次优/成就/百分比”；“革命的情谊”不再作为成就，只保留事件与文本。
4. 限时选项期间禁止打开物资栏；选项结算后、状态变化时再弹。
5. 本文件只定规则；具体剧情文本（冬生赠青稞、林先生死因、7(3) 的台词、7(5) 的门板交接）在剧本里补。
