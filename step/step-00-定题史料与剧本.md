## 2. 本步骤的不变量（先背下来再动笔）

**史实（改一条就返工）**

1. 大事件结局不可改：湘江必败、遵义必开、泸定必夺。
2. 真实人物（毛泽东、周恩来、刘伯承、陈树湘、黄开湘、杨成武等）只进 `docs/codex.md`，**正文一个名字都不能出现**，更不许有台词。
3. 争议细节必须写"有不同说法"：X 光机、22 勇士牺牲人数、金沙江船数（6/7）、夹金山高度。
4. 史实 / 回忆录 / 文学三分：`docs/sources.md` 的「类型」列只能取这三个值；《七根火柴》《金色的鱼钩》是小说，不得进图鉴、不得当引文。
5. 每条史实注末尾带出处编号（S1–S7）。

**情感**

6. 虚构声明（满崽与名册人物虚构）在片头与图鉴各出现一次。
7. 死亡只写"划名 + 留白 + 物件"；不写枪声细节、不写血、不写尸体。
8. 牺牲不做分数、不做"完美通关"评价；小游戏失败只改代价。
9. 敌人只作为时间压力与追兵出现，不给脸谱化描写。

**玩法**

10. 每章 2–3 个选项，选项必须是取舍；每个选项都要有 `cost`（可读的一句代价）。
11. 限时选项必须有 `timeout` + `defaultOption`；超时按默认项结算并记录 `timedOut`，不许"免费超时"。
12. 单一结局；旗标只改变细节（带什么、救谁、记住谁），不生成分支结局。
13. 核心版 4 个真小游戏：门板 / 弃物 / 渡船 / 攀索；点名不算第 5 关；草地纯对话。

**范围**

14. 文本量是最大成本：先三场重头戏，其余章允许停在 beat 级大纲。
15. 20 分钟硬验收；超时按"草地 → 金沙江 → 遵义纯对话"裁，保留序章/湘江/泸定/点名。

| **D7** | 五卡必须可失败（见 §5.4 审计表）；`fire ≥ 20` 替代原 `fire ≥ 1`；`memory.zhang` 改为可失败 | 原阈值下 2 张卡"必然点亮"，等于把精神写成口号 |

**D2 的算式**（决定 4100 的依据，执行时照抄进 §4.1）：

- 每行均长 22 字；正常点按：阅读 7 字/秒 + 每行点击 0.5 秒 → **0.166 秒/字**；慢读：4.5 字/秒 + 0.8 秒/行 → 0.258 秒/字。
- 4100 字：A 口径 680 秒（11:20）／B 口径 1058 秒（17:38）。
- 交互固定开销：小游戏实际 225 秒（50/55/65/55；上限是 75/80/90/75，玩家通常提前结算）+ 选项 72 秒 + 图鉴 7×10 秒 + 点名 45 秒 + 错误卡 40 秒 = 452 秒（7:32）；再加标题/地图/转场 45 秒 → 497 秒（8:17）。
- **A 口径合计 680 + 497 = 1177 秒 ≈ 19:37**（距硬线 20:00 只剩 23 秒，所以任何一章都不许擅自加字）；**B 口径 1058 + 497 = 1555 秒 ≈ 25:55（不可接受）**。
- 结论：验收口径 = A（正常点按）。预算 19:37 / 预警线 19:45 / 硬线 20:00；实测 >19:45 就按裁剪顺序减 300 字（≈50 秒）复测，记录进 `docs/test-record.md`。
